# v2 規格 G — 事故記錄計分 & 收容終演(核心循環重排)

> 【狀態】**已定案(使用者拍板 2026-08-01),待實作**。實作分兩刀:flow-1a(記錄計分)→ flow-1b(收容終演)。
> 來源:玩家試玩回饋「每一回合都要回收,感覺很不流暢」+ 使用者方向「把回收當成打贏後的最終場表演,
> 中間回合要有其他行為;終演=相機特寫,玩家只按表演按鈕,人物自動搬運+丟」。
> 關係:**重排規格 F §2.5 的回合模型**(三段收容→記錄×N+終演×1);規格 E 北極星不變且被強化
>(報告是核心產物——本規格就是把「餵報告的動作」搬回主循環)。

---

## 0. 一句話

> **讓對手失能=蓋一筆「事故記錄」(得分);記錄集滿=「收容指令」下達;此後第一次打暈對手=按下表演鍵,
> 角色自動抓起、扛去回收艙封存——一鏡到底的終場演出,一局只演這一次。**

貴的儀式只做一次才是簽名,重複三次就是雜務(MK Fatality / Smash 終結慢鏡的教訓)。

## 1. 為什麼改(證據)

1. **玩家回饋**:「每回合都要回收很不流暢」——收容鏈太貴(暈 1.2s 內要靠近到 46px、抓、0.6 倍速扛到場中央、可被掙脫),被逼重複 3 次。
2. **實測(AI 對局 ×2,build ugc-6)**:七次得分**全部是墜落**,抓→扛→丟艙**零次**;報告兩場都是最低 D 級
   (chaos 素材=carries/拋射/反向收容,全依賴沒發生的抓丟鏈);run1 第 1 分後**空窗 116 秒**。
   → 招牌動作被便宜的墜落路擠出比賽;北極星產物(好笑報告)被餓死。
3. **結構暗示已存在**:`PERFORM_T = [2.1, 2.6, 3.6]` 越演越大——前兩次本來就是縮水版,只有最後一次是完整演出。

## 2. 得分動詞表(中段回合)

**規則一句話:對手任何「失能」= 你 +1 記錄。**(1v1:失能者的對面得分,含自摔/自炸——歸因交給報告去笑)

| 失能事件 | 記錄 | 現場呈現(不打斷流程) |
|---|---:|---|
| 擊暈(穩定值歸零,任何來源:連段/衝刺/下壓/火/毒/電/燃燒鏈) | +1 | 蓋章特效+hitstop 0.2+HUD pip 亮;**不重置場地、不演出**,打續 |
| 墜落出場(fall) | +1 | 受害者出生點重生+短保護(沿用);快速橫幅,無演出 |
| 中段被弄進艙(滑/吸/拋/爆) | +1 | **拒收吐回**:短演出「檔案不齊,拒收!」→北管道吐回(≈2s)。艙=中段玩具:好笑+得分但**不能提前贏** |
| 普通推擠/碰撞/掉瓶 | 0 | |

- 去重:記錄在 `stunned` **false→true 轉換**時記一次;`RESTUN_IMMUNE`(0.6s)天然防連刷。挑飛(對已暈者)不再記。
- 擊暈閥值機制**完全不動**(100 穩定值/傷害表/回復 28/暫停窗)——本規格只改「暈了之後算什麼」。
- **軟重整退役**:中段不再重置位置/場地(玩家嫌的「不流暢」主要就是它)。場地狀態(地板化學/桶)自然延續=後期越來越亂,正好餵階段升級的敘事。

## 3. 賽末點:收容指令

- `RECORD_TARGET = 3`(旋鈕):任一方集滿 3 筆記錄 → **收容指令下達**。
- 呈現:頂部橫幅「⚠ 收容指令:對 {對手} 執行收容封存」、回收艙開始發光脈動、教練線「打暈他,按 X 收容!」。
- 階段對映(沿用現有 `applyStage`,觸發點從「每次收容後」改為「記錄數」):
  領先者 0–1 筆=階段1 普通;2 筆=階段2 黃色警戒;3 筆(指令下達)=階段3 全面失控——「全面失控所以總部下令收容」,敘事剛好接上。
- 雙方可同時處於賽末點(3:3),誰先打暈誰就先演——最高張力態,不需特殊規則。
- 賽末點期間的其他失能:對手**墜落**=直接 `fallSeal`(人已墜井,現成路徑);對手**進艙**=直接封存(人已在艙裡);
  自己反被打暈=對手 +1 記錄(可能反轉成對方的賽末點)。

## 4. 收容終演(finisher;一鏡到底)

### 4.1 觸發與按鍵

- 條件:你已達賽末點,且**你把對手打暈**(任何失能來源中,只有「暈」可觸發終演——倒在你面前才有戲)。
- 此時受害者的暈眩延長為 `FINISHER_WINDOW = 2.5s`(讀作「他知道結束了」),HUD 出現大提示:**按 X 收容**
 (沿用互動鍵=抓的肌肉記憶;觸控=抓鍵發光放大)。AI 達成條件時延遲 0.5s 自動按(玩家看得懂發生什麼)。
- **窗口內沒按**:對手照常醒來(保底 40 穩定),比賽繼續——不強迫,錯過=自己的選擇。

### 4.2 按下之後(全自動,玩家放手)

```text
T0 按下:hitstop 0.3 + 白閃 + 「收容!」蓋章 → 雙方 input 切斷、AI 停機、雙方 invuln
        (invuln 同時天然免疫地板化學/爆桶波及——floorHazards 對 invuln 早退,現成)
① 自動接近:角色以跑速直線奔向倒地對手(受害者鎖定倒地,不再醒)
② 自動抓起:到 GRAB_RANGE 觸發 startCarry(強制成功,掙扎關閉)
③ 自動搬運:以扛人速度走向回收艙(沿用 AI 的 carry→POD 導航)
④ 自動拋入:到艙緣轉身面向艙心 → throwCarried → 入艙
⑤ 封存:接現有 startPerform 最終版(3.6s 玻璃罩+壓縮+LED)→ 事故報告
```

### 4.3 鏡頭(特寫規格)

- 沿用 CAM live-驅動慣例(intro 的 camRig 框雙人是現成範式):
  - **切入(0.6s lerp)**:`dist 220→130、angle→14、lookY→32`,鎖定跟隨搬運者;azimuth 緩慢漂移 ±0.15rad(電影感微環繞)。
  - **搬運段**:近距跟拍;**拋入瞬間**:急拉回 `dist→260` 框住整個回收艙(接演出的罩+LED)。
  - **演出結束**:1.0s lerp 回正常跟隨值。
- **上下黑邊(letterbox)**:v2-hud 在終演+封存期間畫上下黑條(高度 ~10% 視高,0.4s 滑入)——一條 fillRect 的成本,「過場感」讀法最強。
- 對戰 HUD(狀態卡/教練線)終演期間壓掉(沿用結局期壓 HUD 的慣例)。

### 4.4 邊界情形

| 情形 | 處理 |
|---|---|
| 按下瞬間對手剛好在艙內/井裡 | 不會發生(暈=倒在場上);防禦性:直接走對應 seal |
| 自動接近路徑被牆/桶擋 | 場地是開放矩形+四角圓台,直線可達;桶碰撞=invuln 推開不爆 |
| 搬運中掉落邊緣 | 導航目標=艙心(場中央),不經過邊緣;防禦性:離邊 <32px 內推 |
| 玩家在窗口內按到別鍵 | 其他輸入無效(仍在戰鬥態,只是對手倒著);只有 X 進終演 |

## 5. HUD 讀法

- 三格收容 pips → **三格「事故記錄」章**(⚠ 印章圖形;蓋上時 stamp 動畫)。
- 記錄 +1 飄字:「事故記錄 #N:{事由}」(事由=失能來源短語:連段擊暈/墜落/滑進回收口…)——**就是報告的句子提前現場化**,
  規格 E「報告=體驗而非結算」的第一步。
- 賽末點:橫幅+艙發光(§3);終演:letterbox+提示鍵(§4)。
- 教練線改寫:開場「記錄對手三次事故!」→ 賽末點「按 X 收容!」。

## 7. 旋鈕(起始值,實測再調)

| 旋鈕 | 值 | 備註 |
|---|---:|---|
| `RECORD_TARGET` | 3 | 記錄變便宜(暈≪收容),局長預期縮短;tempo 探針重量後決定 3 或 4 |
| `FINISHER_WINDOW` | 2.5s | 倒地延長窗;太短=撲空挫折,太長=站樁尷尬 |
| `FINISHER_AI_DELAY` | 0.5s | AI 按鍵延遲(可讀性) |
| 拒收吐回時長 | ≈2s | 沿用北管道吐回 |
| 終演鏡頭切入/回正 | 0.6s / 1.0s | |

## 8. 驗收(DoD)

1. AI 對局 tempo 探針重跑:**空窗 ≤ 30s**、每局至少一次完整終演(抓→扛→拋→封存)、報告等級中位數 ≥ C。
2. 終演一鏡到底無操作介入;窗口過期=比賽無縫續打;鏡頭切入/回正無跳切。
3. 中段記錄不重置場地(地板化學延續)。
4. 全套回歸綠;新 `finisher.mjs` 落地 `tests/`。
